# Packages

WetoLoop will use npm workspaces for distributable components. Package boundaries are
reserved here before code is split so the public architecture stays intentional.

Planned packages:

- `core` — provider-neutral contracts and policies;
- `cli` — installation and command-line experience;
- `harness` — deterministic execution and evidence orchestration.

No package is published from this repository at `0.0.1` yet.
