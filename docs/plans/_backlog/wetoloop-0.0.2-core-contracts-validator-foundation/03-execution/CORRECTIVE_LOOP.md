# Corrective Loop

A failed focused gate or independent review enters a bounded corrective cycle.

1. Record the exact finding and detecting evidence.
2. Change only the smallest surface necessary.
3. Rerun the detecting test and directly affected checks.
4. Re-run independent review for the finding.
5. Do not repeat broad audits unless contract, architecture, security boundary or impact scope changed.

Escalate to BLOCKER when resolution requires owner authority, contradicts an approved decision or cannot be completed without expanding approved scope.
