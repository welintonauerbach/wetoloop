# WetoLoop Specifications

This directory contains implementation-ready specifications for WetoLoop public contracts.

Specifications are numbered in dependency order. A specification defines behavior and acceptance criteria; it does not imply that the behavior is already implemented on `main`.

| ID | Specification | Target | Status |
|---|---|---|---|
| SPEC-001 | [Semantic Validator Foundation](001-semantic-validator-foundation.md) | 0.0.2 | Ready for review |
| SPEC-002 | [ImpactSet & Task Verification Contract](002-impactset-task-verification-contract.md) | 0.0.2 | Ready for review |

## Status meanings

- **Draft** — design is incomplete or contains unresolved decisions.
- **Ready for review** — implementation contract is complete enough for review and task decomposition.
- **Approved** — accepted as the implementation authority for its scope.
- **Implemented** — acceptance criteria are satisfied by merged code and evidence.
