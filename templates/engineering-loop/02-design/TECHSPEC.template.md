# Technical Specification

## Architecture and boundaries

Define components, dependencies, authorities and read/write boundaries.

## Detailed design

Describe domain types, adapters, algorithms, failure behavior and concurrency.

## Security and safety

Cover untrusted input, path containment, secrets, command execution and
recoverability.

## Testability and rollout

Map risks to focused tests, sensors, migration, rollback and package gates.
Do not defer task-owned tests to the final validation task.
