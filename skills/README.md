# Skills

This directory is reserved for reusable WetoLoop agent procedures.

The initial skill model is expected to group work by lifecycle responsibility rather than
create one skill per template file:

- initialization and reconnaissance;
- definition and requirements;
- design and contracts;
- task planning and test strategy;
- task execution and corrective loops;
- final validation and learnings.

Skills describe how an agent performs work. Templates and schemas remain the contract, and
harness code remains the deterministic execution layer.
